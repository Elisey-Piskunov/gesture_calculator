# gesture_calculator

распознает жесты рук (цифры 1-5, знаки +- и backspace) через веб-камеру в реальном времени и выполняет базовые арифметические операции.

## 📸 демо 
https://github.com/user-attachments/assets/a9335c4a-bc9d-4c4a-82af-0b67f4967189

## 🧠 Как работает
1. MediaPipe находит 21 ключевую точку на ладони.
2. MLP-модель классифицирует жест по координатам точек.
3. Программа считывает жест при нажатии "S", собирает из жестов арифметическое выражение и вычисляет результат после жеста "=".

## ✨ Доступные жесты
- 1 палец (указательный) - цифра 1
- 2 пальца (указательный + средний) - цифра 2
- 3 пальца (большой - средний) - цифра 3
- 4 пальца (указательный - мизинец) - цифра 4
- 5 пальцев - цифра 5
- 👍(лайк) - операция +
- 👎(дизлайк) - операция - 
- 👌(ок) - операция = 
- мизинец - backspace

## 🧑‍💻 как создавался проект
С помощью MediaPipe собран датасет с жестами (сбор датасета реализован в файле "collect_data.ipynb"). На собранном датасете была обучена реализованная вручную MLP-модель (написанная с использованием PyTorch), которая распознает жесты (реализовано в файле "train_model.ipynb"). Итоговое приложение в реальном времени обрабатывает кадры с веб-камеры, определяет жест и выполняет соответствующее действие (реализовано в файле "gesture_calculator.ipynb")

## 📊 Результаты

- Размер датасета: 9 классов × 100 кадров.
- Обучающая выборка: 90 кадров / класс.
- Тестовая выборка: 10 кадров / класс.
- Точность на тесте: 100%.
- Уверенность программы: ~99% на тестовой выборке.
